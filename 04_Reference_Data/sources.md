# Technical references and scope

Accessed 7 November 2026. These references support format/API choices and tire nomenclature, not design certification.

1. **User-provided brief:** `original_brief.md`, copied unchanged from the user's Downloads folder. All baseline geometry targets come from this source.
2. **Schwalbe tire-size table:** https://www.schwalbe.com/media/97/93/b4/1700219698/Reifengroessen-uebersicht_EN.pdf - maps 700 x 25C to 25-622.
3. **Schwalbe Technology/FAQ:** https://www.schwalbetires.com/technology-faq/ - ETRTO width and tire inner-diameter naming. An approximate French size does not determine a verified inflated CAD envelope.
4. **CadQuery exchange documentation, project source:** https://github.com/CadQuery/cadquery/blob/master/doc/importexport.rst - STEP assembly export and DXF exchange. This project uses CadQuery 2.6.1, not an assumed current release.
5. **Git LFS project:** https://git-lfs.com/ and https://github.com/git-lfs/git-lfs/blob/main/docs/man/git-lfs.adoc - binary asset attributes and local hooks. LFS tracking does not constitute a remote backup.
6. **SolidWorks API documentation:** See the exact primary API links in `../06_Automation/SOLIDWORKS_BUILD.md`.

Tube sections, reference component shapes and additional fit dimensions are project assumptions. They were not sourced from a supplier and must not be presented as approved supplier requirements.
